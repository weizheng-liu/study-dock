# Study Dock 浏览器采集助手

读取本人已登录的 `nu.instructure.com` 和 Google Classroom 页面，通过一次性配对码把内容传给本机 `http://127.0.0.1:8840` 的学习空间。

## Windows 快速打开

Chrome 版已在本机部署时，双击项目上一层的 **打开采集助手（Chrome）.cmd**，会打开独立 Chrome 配置中的学习空间与助手。配对保存在该配置中，日常启动不需要重复填写。Chrome 与 Edge 的平台登录和插件配对各自独立。

双击项目上一层的 **打开学习空间与采集助手.cmd**。它使用独立的 Edge 配置目录，打开网页和已加载插件的页面，不复制你现有浏览器中的账号或 Cookie。

## 手动安装到自己的 Chrome / Edge

1. 从学习空间“账号连接”下载插件 ZIP 并解压；或直接使用项目的 `extension` 文件夹。
2. 在地址栏打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择**直接包含 manifest.json 的文件夹**。
4. 把 Study Dock 固定到工具栏，方便打开。

如果学校管理的浏览器禁止安装扩展，需要使用允许安装的个人浏览器或等待管理员允许；插件无法改变这项策略。

## 配对和采集

1. 在本机学习空间注册或登录本站账号，进入“账号连接”，生成一次性配对码。
2. 打开插件，粘贴配对码并连接。配对码十分钟内有效，只能使用一次。
3. 在插件中分别打开 Canvas / Classroom 官方页面，手动完成学校账号登录。密码、二步验证都在官方页面完成，不交给插件或本站。
4. 确认插件中选择的“学校网页显示的时区”。默认日本时间 UTC+9。
5. 点击该平台的“绑定并同步当前账号”。Canvas 会读取账号设置页的用户标识；Classroom 读取右上角当前 Google 账号标识。有多个 Google 账号时，应先在目标 Classroom 标签页切到学校账号，再打开插件绑定。
6. 回网页查看课程与日历。首次采集会逐页打开一个后台标签页，完成后自动关闭。

浏览器和本机程序运行期间，每十五分钟尝试更新；网页“同步课程”的请求通常在一分钟内被插件检查到。默认最多读取一百五十页，达到上限会提示部分内容未读取。浏览器休眠或关闭时不保证更新。

## 明确的边界

- Canvas 优先读取当前学生可访问的同源作业列表，取得个人截止时间和提交方式，再读取课程模块。Classroom 从课程页面读取。
- 文字作业可在学习空间保存草稿。打开原平台的文字回答框，点击「填入学习空间草稿」，核对后点击「确认并提交这段文字」。原平台如有额外确认，以其回执为准。
- 不申请 Cookie、历史记录或所有网站访问权限。只匹配两个平台和本机网页；不读取密码框的值。
- 配对令牌只用于向指定本机学习空间导入数据，不是学校登录凭据。可在网页撤销该插件的配对。
- 采集前后都确认账号一致；发现切换账号会停止导入。主动重绑另一个账号时，会清除该平台旧缓存。
- 逐页识别课程、作业详情、学习资料、附件链接及公告。折叠内容会尝试展开，但页面改版、虚拟列表和没有可访问详情入口的内容仍可能无法完整识别。
- 仅完整日期和时刻、或网页提供的明确时间戳会排入日历。缺少年份、时刻等信息时保存原文并标记“日期待确认”。不会把发帖时间当作截止时间。
- 增量合并，不因本次页面里没出现旧内容就自动删除。详情页数据优先于列表摘要。
- 这是可安装、可连接网页的首版采集器。自动化测试使用模拟学校 HTML；你学校真实页面的语言、布局、账号标识和日期格式仍需要登录后验证。

无需在聊天中发送密码、Cookie、验证码或配对令牌。
